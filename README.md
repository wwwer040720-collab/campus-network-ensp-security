# 河北地质大学校园网络仿真项目（eNSP）

基于华为 eNSP 模拟器搭建的**校园网组网 + 网络安全攻防演练**仿真项目。以河北地质大学校园网为原型，构建了校本部、北校区、南校区、运营商接入点四大场景，覆盖从接入层到核心层的完整三层园区网络，并配套 **7 套网络安全事件应急预案**（ARP 欺骗、MAC 洪泛、TCP SYN 洪水、DHCP 饥饿、SSH 暴力破解、Web 目录扫描、端口扫描），可用于计算机网络课程实训、红蓝攻防演练与应急响应流程演练。

## 项目亮点

- **完整三层园区网**：接入层 — 汇聚层 — 核心层，9 台接入交换机、6 台汇聚交换机、2 台核心交换机分级组网
- **多校区互联**：校本部通过双出口路由器分别互联北校区、南校区及两家运营商，出口链路冗余备份
- **高可用设计**：双核心交换机 STP 根桥 / 次根桥冗余 + VRRP 虚拟网关，楼宇汇聚双链路上联
- **路由与地址**：OSPF（骨干区）承载校区互联，静态路由补充默认路由与回程路由；核心交换机内置 DHCP 服务，按 VLAN 自动分配地址
- **纵深安全**：防火墙安全域与区域安全策略、ACL 访问控制、NAT 出口转换与 NAT Server 端口映射、端口安全、DHCP Snooping、DAI、静态 ARP 绑定、SSH 访问白名单
- **攻防演练配套**：7 套标准化的网络安全事件应急响应报告（事件概述 / 业务信息 / 处理过程 / 修复方案 / 验证 / 结论建议）

### 关键技术与安全设计

| 设计项 | 说明 |
| --- | --- |
| 二层冗余 | 双核心 STP 根桥 / 次根桥；管理 VLAN 900 配置 VRRP 虚拟网关 192.168.255.254，实现设备网关冗余 |
| 路由协议 | OSPF（骨干区 Area 0）承载核心 — 出口 — 校区 — ISP 互联；静态路由配置默认路由与回程路由，部分链路通过 preference 设置主备优先级 |
| 地址分配 | 核心交换机 DHCP 地址池（租期 7 天，DNS 114.114.114.114 / 8.8.8.8），终端自动获取 IP |
| NAT 转换 | 出口路由器 NAT outbound（地址组 61.182.28.1）实现内网访问外网；ISP 侧 NAT Server 将公网 80 端口映射至内网 Web 服务器 |
| 防火墙策略 | FW2 划分 trust / untrust / dmz 安全域，配置行政 — 财务互访放行、其他区域访问财务拒绝、VLAN20 禁止访问外网等区域安全策略 |
| 访问控制 | 核心交换机 ACL 限制内网对网管服务器（192.168.200.10）的访问；SSH 远程管理配置访问白名单并开启登录防暴力破解 |
| 二层安全 | 接入交换机启用端口安全、stp edged-port；应急预案中配套 DHCP Snooping、DAI、静态 ARP 绑定等加固方案 |
| 运维管理 | SNMP 告警接入网管平台（192.168.200.30），日志上报日志服务器（192.168.200.31），管理地址规划于 VLAN 900 / 901 |

## 攻防演练与应急预案

| 攻击类型 | 攻击现象 | 处置流程 | 关键防护措施 |
| --- | --- | --- | --- |
| ARP 欺骗 / 中间人攻击 | 内网卡顿、丢包、间歇断网，明文流量被劫持嗅探 | 排查异常 ARP → 隔离攻击主机 → 清除错误缓存 → 静态绑定 → 全网加固复测 | DAI 动态 ARP 检测、IP+MAC 绑定、静态 ARP、缩小广播域、HTTPS 加密 |
| MAC 洪泛攻击 | 交换机 MAC 地址表溢出、全网泛洪、广播风暴 | 定位攻击端口 → 关闭端口 → 清空 MAC 表 → 开启端口安全 → 复测 | 端口安全（限制 MAC 学习数）、风暴控制 |
| TCP SYN 洪水攻击 | 半连接队列占满、CPU / 带宽飙升、网站无法访问 | 识别攻击 → 阻断流量 → 释放连接 → 参数优化 → 复测验证 | ACL 封禁攻击源、SYN Flood 防护、单 IP 连接数限制、TCP 协议栈调优 |
| DHCP 饥饿攻击 | DHCP 地址池耗尽、新终端无法获取 IP、广播激增 | 定位攻击源端口 → 关闭端口 → 释放地址池 → 开启防护 → 复测 | 端口安全、DHCP Snooping、缩短地址租期、合理规划地址池 |
| SSH 暴力破解 | 大量异地高频登录失败日志、CPU 升高、弱口令风险 | 定位攻击源 → ACL 封禁 → 核查风险 → 修改强口令 → 策略加固 | SSH 访问白名单、登录重试限制、强口令整改、关闭 Telnet |
| Web 目录扫描 / 目录遍历 | 海量 404 请求、CPU 飙高、敏感目录与备份文件泄露 | 封禁攻击源 → 重启服务 → 关闭目录浏览 → 请求限流 → 复测 | 关闭目录浏览、请求频率限制、敏感目录 IP 白名单、部署 WAF |
| 端口扫描 | 高频端口探测、访问日志刷屏、设备 CPU 波动 | 攻击溯源 → 阻断流量 → 端口收敛 → 策略加固 → 复测 | 最小端口开放原则、连接数 / 速率限制、网段隔离、核心端口白名单 |

每份应急预案报告均包含：事件概述（现象 / 时间 / 关键字）、业务信息（服务器 IP、机房位置、服务框架、防火墙策略、周边环境）、处理过程（时间线记录）、修复方案（紧急修复 / 短期加固 / 长期优化 + 验证）、结论建议，可直接作为实训演练脚本使用。
